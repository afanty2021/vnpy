## 🎯 需求概述

### 核心目标

构建一个**稳定、安全、高效**的 A 股量化交易系统，支持：
- 符合 A 股交易规则的策略运行
- 完善的风险控制机制
- 丰富的行情数据分析
- 灵活的策略开发框架
- 可靠的监控告警体系

### 设计原则

1. **安全第一**：资金安全高于一切，严格的风控体系
2. **规则合规**：严格遵守 A 股交易规则（T+1、涨跌停等）
3. **稳定可靠**：系统稳定运行，异常情况及时处理
4. **扩展灵活**：模块化设计，便于功能扩展
5. **性能优先**：高效数据处理，低延迟交易执行

```python
class ChinaStockStrategy(CtaTemplate):
    """A股策略基类"""

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.trading_rules = ChinaTradingRules()

    def check_trading_rules(self, order: OrderData) -> bool:
        """交易规则检查"""
        # T+1检查
        if not self.trading_rules.check_t1_sellable(order.symbol, order.volume):
            self.write_log("T+1规则限制，当日买入不可卖出")
            return False

        # 涨跌停检查
        limit = self.trading_rules.get_price_limit(order.symbol)
        if not self.trading_rules.is_price_valid(order.price, limit):
            self.write_log(f"价格超过涨跌停: {limit}")
            return False

        # 交易单位检查
        if not self.trading_rules.check_volume_unit(order.volume):
            self.write_log("交易单位必须是100股的整数倍")
            return False

        return True
```
