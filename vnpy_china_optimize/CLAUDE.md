## 核心功能

### 1. 优化算法

#### 贝叶斯优化 (BayesianOptimizer)
- 使用高斯过程代理模型
- 期望改进（EI）采集函数
- 适合计算代价高的优化问题

```python
from vnpy_china_optimize import BayesianOptimizer

def objective(params):
    return -(params["x"] - 2) ** 2 - (params["y"] + 3) ** 2 + 20

optimizer = BayesianOptimizer(
    objective_func=objective,
    param_space={"x": (-10, 10), "y": (-10, 10)},
    n_initial=10,
    random_state=42
)

summary = optimizer.optimize(n_iterations=50)
```

#### 粒子群优化 (PSOOptimizer)
- 模拟鸟群觅食行为
- 支持惯性权重衰减
- 适合连续参数空间

```python
from vnpy_china_optimize import PSOOptimizer

optimizer = PSOOptimizer(
    objective_func=objective,
    param_space={"x": (-10, 10), "y": (-10, 10)},
    population_size=30,
    random_state=42
)

summary = optimizer.optimize(n_iterations=100)
```

## API文档

### BaseOptimizer

优化器基类，所有优化算法继承此类。

**方法:**
- `optimize(n_iterations, **kwargs) -> OptimizationSummary`: 执行优化
- `evaluate(params) -> float`: 评估参数组合
- `get_summary() -> OptimizationSummary`: 获取优化汇总

### OptimizationResult

优化结果数据类。

**属性:**
- `params: Dict[str, Any]`: 参数
- `metrics: OptimizationMetrics`: 指标
- `score: float`: 综合评分

### OptimizationSummary

优化汇总数据类。

**属性:**
- `total_evaluations: int`: 总评估次数
- `best_score: float`: 最优分数
- `best_params: Dict[str, Any]`: 最优参数
- `all_results: List[OptimizationResult]`: 所有结果

**方法:**
- `get_top_n(n)`: 获取前N个结果
- `get_parameter_ranking(param_name)`: 获取参数排名
